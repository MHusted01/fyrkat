# Code of Conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
by reference. Its text, including the pledge, standards, enforcement responsibilities and
enforcement guidelines, applies to all project spaces: the repository, issues, pull requests,
discussions and any other channel where people represent the project.

## Reporting

Report unacceptable behaviour privately through GitHub. Use the repository's **Security**
tab and **Report a vulnerability** form, and mark the report as a conduct matter in its
title, because the repository has no separate private channel. Do not post the report in a
public issue or discussion.

Reports are handled by the project owner, who keeps the reporter's identity confidential.
If the report concerns the owner, say so in the report and state who else you want to
review it.
